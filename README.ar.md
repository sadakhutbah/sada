<h1 align="center">صدى · Sadā</h1>

<p align="center">
  بثّ مباشر تلقائي لخطبة الجمعة، مع معالجة بالذكاء الاصطناعي تحوّلها إلى نصوص وترجمات ومقاطع قصيرة.
</p>

---

يعمل «صدى» على حاسوب صغير في المسجد. يتابع مواقيت الصلاة، ويبدأ البثّ المباشر من تلقاء نفسه حين يصعد
الإمام إلى المنبر، ويتوقّف عند بدء الصلاة، ويرسل البثّ نفسه إلى فيسبوك أو يوتيوب أو أي وجهة RTMP.
وبعد انتهاء البثّ، يفرّغ الخطبة نصًّا، ويتعرّف على الآيات القرآنية الواردة فيها، ويترجمها، ويُعدّ
مقاطع قصيرة لا تُنشر إلا بعد أن يراجعها إنسان ويوافق عليها.

لا حاجة إلى أن يبقى أحد خلف الكاميرا.

## المزايا

- **بثّ دون تدخّل**: مواقيت الصلاة من «مواقيت» (Mawaqit)، وبدء البثّ عند سماع الصوت ورصد الحضور على
  المنبر، ورصد نهاية الخطبة حين يستدير الإمام نحو القبلة. وتبقى الأوامر اليدوية متاحة (‎+5 دقائق،
  الجنازة، الإيقاف، إلغاء بثّ اليوم).
- **بثّ إلى وجهات متعدّدة**: مُرمِّز واحد وعدّة مخارج RTMP؛ وتعطّل منصّة لا يوقف المنصّات الأخرى.
- **شاشات كاملة**: قبل البثّ، الصلاة، الاستراحة، النهاية، الجنازة، نهاية الدرس، بنصوص يعدّلها كل مسجد.
- **الدروس والمحاضرات**: مواعيد أسبوعية أو لمرّة واحدة، في وقت محدّد أو بعد صلاة معيّنة.
- **المعالجة بعد البثّ**: تفريغ صوتي (faster-whisper)، ورصد الآيات القرآنية، وترجمة، وملخّص، ومقاطع
  بترجمة مدمجة. يعمل مع أي نموذج لغوي محلّي أو بعيد (واجهة متوافقة مع OpenAI أو Anthropic)، ويستمرّ
  بحلول بديلة عند غيابه.
- **لوحة الإدارة**: تطبيق ويب يعمل على الهاتف، بأدوار (مدير، مسؤول، إمام)، وموافقة بشرية قبل كل نشر،
  وسجلّ كامل للعمليات.
- **النشر**: صفحة فيسبوك، يوتيوب، مقاطع إنستغرام (Reels)، أو مجلّد محلّي. مع رفع اختياري للتسجيلات
  إلى S3 أو Cloudflare R2.
- **الخصوصية أولًا**: الكاميرا لا تصوّر إلا المنبر، وإشارات الحضور والوجه تُحسب لحظيًّا، ولا تُحفظ
  أي صورة ولا أي هوية.

## طريقتان للاستخدام

- **استضافة ذاتية**: تثبيته على حاسوب المسجد (هذا المستودع).
- **النسخة المستضافة**: يسجّل المسجد دخوله إلى النسخة المستضافة ويبثّ من OBS، دون أي تثبيت.

## البدء السريع

المتطلّبات: ‏Python 3.10 أو أحدث، و[uv](https://docs.astral.sh/uv/)، و`ffmpeg`، ومرحّل
[mediamtx](https://github.com/bluenviron/mediamtx) للبثّ المباشر (يكفي وضعهما في `tools/bin/`).

</div>

```bash
make setup                 # virtualenv + dependencies
python -m sada.installer   # checks the machine and says what is missing

# create the mosque and its first administrator (password asked interactively)
.venv/bin/python -m sada.backoffice create-admin --username admin \
    --mosque my-mosque --mosque-name "My Mosque"

make backoffice            # http://<this-machine>:8090
```
